# Design direction v3 brief (Fable, 2026-09-21) — "Apple Mail-informed, monotone glass"

Logan's direction: the current UI feels like a kinso copy with a grid-pattern canvas. He wants a monotone, more glassy, simpler, more intuitive, easier-on-the-eyes UI, and he supplied Apple Mail iOS (Feb 2026, iOS 26 Liquid Glass) as the reference for look, feel, usability and product flow: 171 screenshots in `apple-mail-ios/` (onboarding, inbox with category chips, message view, compose, filters sheet, mailboxes list, VIP, drafts, search, markup, print). Product structure and direction stay as they are (unified inbox + agents + approvals + memory; rail of channels; ask bar; kinso-style AI summary rows). This brief sets the direction; Opus structures it into an implementable `DESIGN-DIRECTION-v3.md`; DeepSeek implements; Opus verifies.

## What we take from Apple Mail (and what we keep from kinso)
1. Canvas: plain monotone paper — `--bg-base` near-white, no grid, no pattern, no tinted wash. Content areas are flat white; depth comes only from glass chrome floating above it and from very soft shadows on floating panels.
2. Chrome is Liquid Glass: the rail plate, the top ask capsule (desktop) / the floating bottom bar (mobile), sheets, popovers/menus, the AI panel. Glass recipe per ACCENT-DIRECTION §4.4 (translucent white tint, blur + saturate, 1px inner light edge, soft wide shadow, large radius). Aurora accents stay only where ACCENT-DIRECTION allows (rail plate faint, AI panel, onboarding) and must not fight the monotone base.
3. Inbox header like Mail: large title ("Inbox"), one-line grey subline ("Updated just now" / count), then a single row of category chips (all / work / personal / agents / needs-approval) styled as Mail's category pills: one horizontally scrolling group, active chip tinted with the accent, the rest plain grey on white; the Archived toggle and "+ Label" become icon buttons at the row's end.
4. Rows like Mail but with the kinso AI summary: avatar/brand tile (40px), sender/title bold 15px, one-line AI summary 13px grey (kinso), time 12px tabular right, unread dot, hairline separators between rows inset from the text column (Mail uses hairlines; we now allow them in lists at ≤ 8% ink), swipe actions on touch (archive / snooze / more), hover actions on desktop.
5. Detail view like Mail: sender avatar + name + "To: me" line, subject as the title, generous body typography (17/15 with 1.5 line-height), attachments as cards, a floating glass action bar (reply / archive / more) at the bottom on mobile and a compact glass toolbar at the top on desktop; approvals and agent tool calls render as inline cards in that body (no card wall).
6. Sheets and menus like Mail: filters as a bottom sheet with toggles and checkmarks; contextual menus as glass popovers with SF-style icon + label rows; confirmation actions as inline glass prompts (e.g. "Unsubscribe from mailing list?" pattern) — our equivalents: "Approve this action?", "Archive 3 threads?".
7. Rail (desktop) and bottom bar (mobile): drag-to-reorder the channel/agent icons with fluid, water-like motion — items flow around the dragged one with springs (use the `motion` library's Reorder / layout animations if `motion`/`framer-motion` is already a dependency; check package.json first; otherwise Pointer Events + FLIP with spring easing), long-press to start on touch, haptic-like scale-up on lift, settle with a soft spring; order persists in settings (`ui.rail_order`); reduced-motion = instant reorder. The Agents tile uses Logan's new mascot icon (`packages/ui/src/assets/brands/agent@{1x,2x}.png`, already committed on plan/design-w1).
8. Color: monotone greys + one accent (blue, only for active/selected/links/primary button) + brand marks. No decorative gradients on the canvas. Text ink scale per ACCENT-DIRECTION §1.
9. Motion: Mail's restraint — sheets slide with spring, chips cross-fade, list rows animate height on archive; nothing bounces for decoration.

## Non-goals
- No dark mode yet. No change to the three-pane/two-pane/single-pane breakpoints from D2b. No new dependencies unless already installed.
